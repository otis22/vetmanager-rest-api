# Совместимое расширение по OpenAPI для минорного выпуска

## Контекст и цель

Источник — PR #28, `Roadmap.md` и `Tasks.md` (O2–O8), фиксированный снимок OpenAPI 1.3.1. Расширить возможности PHP-библиотеки, сохранив все ранее допустимые имена, сигнатуры и результаты `asString()` / `asKeyValue()`. PHP 7.3 остаётся нижней границей. Версию в этом PR не выпускать.

## Решение и приёмка

1. O2: построить машинную матрицу всех 104 путей и 137 операций из JSON-снимка с точным регистром первого сегмента, категориями имени и явным уровнем поддержки. Записать в `PRD/reviews/openapi-model-probes.md` статусы GET на devtr6 для 6 отсутствующих, 11 вариантов регистра и 13 имён только библиотеки. Только подтверждённые имена добавить в `Model`, не удаляя 51 старое имя. Для POST-only и других непроверяемых GET путей указать «не подтверждено»; метод сам по себе не реализован библиотекой. Проверять адрес через `vetmanager-url`, а не предполагать домен по имени окружения.
2. O3: добавить `URI\OpenApiPath::__construct(string $template, array $parameters = [])` с `asString(): string` и функцию `openApiPath(string $template, array $parameters = []): URI`. Шаблон — точный путь относительно `/rest/api/` из 19 нестандартных путей снимка, с сохранением регистра. Неизвестный шаблон, пустое значение, лишний или пропущенный параметр бросают `InvalidArgumentException`; имена `{ID}` и `{id}` различаются. `rawurlencode` каждого значения, `.` и `..` отклоняются для защиты префикса. Тесты охватывают `/`, `?`, `#`, `%2F`, Unicode, пустое значение, dot-сегменты и стабильность `uri(model, int)`.
3. O8a: `scripts/check_openapi_contract.py` и `docs/openapi/operation-support.json`: решения об URI-поддержке хранятся в явных списках `Model` и `OpenApiPath::TEMPLATES`; матрица всех операций генерируется из этих решений и снимка. HTTP-методы и схемы явно отмечены как `none`. Скрипт проверяет контрольную сумму, уникальность `operationId`, локальные `$ref`, число путей/операций и точное соответствие карты текущему снимку и исходному коду. CI выполняет `python3 -I scripts/check_openapi_contract.py`. O8b, таблица покрытия схем и проверка после O4–O7, остаётся в очереди.
4. O4: слой HTTP-методов проектировать после подтверждения конкретных method/path/query/body/status; пока нет нового HTTP-клиента. O5: в `PRD/openapi-contract-research.md` собрать сводную ведомость 36 схем и 39 request body; непроверенные по devtr6 свойства помечать явно. O6: в том же документе записать матрицу будущей опциональной валидации, не меняя `Builder`. O7: там же записать проверяемый план авторизации и ошибок devtr6 без клиентских данных. O4–O7 остаются `todo` до доказанной приёмки по `Tasks.md`.
5. Отдельный major-этап: нормализация регистра старых имён, удаление имён только библиотеки, глобальная строгая схема/валидация, изменение старой сериализации или запрет старых способов авторизации. Каждый такой вариант несовместим и в минорный PR не входит. Обновить `Tasks.md` и `Roadmap.md` со ссылкой на PRD и точными статусами.

## Гейты

До кода — независимое ревью этой постановки; после кода — независимое ревью diff с разбором замечаний. `make all PHP_VERSION=8.3`, локальные проверки PHP 7.3 и 8.5 в чистых checkout при доступном Docker, `make integration` только с тестовым devtr6, `python3 scripts/check_openapi_contract.py`, `git diff --check`. CI-матрица PR на итоговом SHA обязательна до merge. Точные команды, exit codes и ограничения записать ниже после выполнения.

## Ревью и результаты

21.10.2026 Claude Sonnet проверил полный текст PRD вместе с Roadmap/Tasks. Четыре замечания приняты: добавлены индивидуальные devtr6-пробы 6+11+13 имён, определён контракт безопасного URI и защита от dot-сегментов, разделены O8a/O8b и источники ручной/генерируемой карты, указаны артефакты O4–O7 и целевые статусы. Проверяемые результаты ниже.

После реализации Claude Sonnet получил фактический diff исполняемого кода, тестов, документации и CI, а также полный текст новых `OpenApiPath`, тестов, проверочного скрипта и исследовательских PRD. Независимое read-only ревью вернуло `[]` — серьёзных замечаний нет. После удаления нестабильного нового интеграционного теста и обновления документации повторное независимое ревью итогового diff также вернуло `[]`. Отдельная статическая сверка с `HEAD` показала сохранение всех 51 прежних имён `Model` и всех существовавших публичных сигнатур в изменённых файлах; добавлены 14 имён и `openApiPath()`. Выполненная на PHP 8.3 проверка всех 51 старых имён подтвердила прежние строки `Model::asString()`, `uri($name)` и `uri($name, 17)`.
