# Совместимое обновление dev-зависимости URL в PR #25

## Задача и контракт

PR #25 пытался обновить `otis22/vetmanager-url` до 1.0.1. Прямо пакет указан здесь только в `require-dev`, в примерах и интеграционных тестах; через `vetmanager-token` он также входит в граф runtime-зависимостей. `src/` и публичный контракт `asKeyValue()` / `asString()` не меняются. Поддержка PHP 7.3–8.5 и полный CI остаются обязательными.

## Выявленный конфликт

Версия URL 1.0.1 требует PHP >=7.4. `otis22/vetmanager-token` 0.2.3 допускает URL `~0.1 || ^1.1`, а 0.2.2 — `~0.1`. Поэтому честная фиксация 1.0.1 не разрешается, а alias `1.0.1 as 0.1.999` из PR обходит объявленный контракт token-пакета. Тот же alias фиксирует ровно 1.0.1 и не даёт обновляться в линейке.

## Решение и приёмка

1. Заменить alias диапазоном `^0.3 || ^1.1`: Composer выбирает совместимую URL-версию на PHP 7.3 и актуальную 1.1.x на PHP >=7.4. Это меняет формулировку первоначального PR; описание PR обновить до фактического решения.
2. Проверить разрешённые версии URL/token: ожидаются URL 0.3.x на PHP 7.3 и URL 1.1.x на PHP 7.4+, а также совместимая версия token. Выполнить `make all` на PHP 7.3, 8.3 и 8.5, `composer validate --strict`. Все 12 jobs CI (latest PHP 7.3–8.5, minimum и production на краях) должны быть зелёными для итогового SHA.
3. Запустить `make integration` только на devtr6 и указать прошедшие/пропущенные тесты. Не читать и не печатать тестовый ключ.
4. Получить независимое ревью этого решения до финального изменения и ревью итогового diff после него. Записать точные команды, коды завершения и ограничения здесь.

## Совместимость

Runtime-зависимости и публичный API пакета остаются прежними; повышение major-версии `vetmanager-rest-api` не требуется. URL 1.0.x не тестируется напрямую, поскольку этот вариант нельзя честно совместить с текущей зависимостью token и поддержкой PHP 7.3. Его отдельная поддержка потребует нового ограничения в `vetmanager-token`; для всей матрицы дополнительно нужна альтернативная URL-версия на PHP 7.3 либо изменение upstream PHP-ограничения.
